# 游戏大厅新功能 - 快速开始指南

## 🎮 新功能概览

游戏大厅现在支持 4 种加入游戏的方式：

1. **输入桌号** - 快速加入好友的游戏
2. **快速匹配** - 自动找到或创建游戏
3. **浏览大厅** - 查看所有公开游戏
4. **接受邀请** - 好友邀请直接进入

---

## 🚀 使用场景

### 场景 1：和好友一起玩

**创建者：**
1. 点击"创建游戏桌"
2. 选择游戏（如五子棋）
3. 选择"公开桌子"或"私密桌子"
4. （可选）勾选"设置密码保护"
5. 点击"创建"
6. 告诉好友桌号（如 #1234）

**好友：**
1. 点击"输入桌号"
2. 输入桌号：1234
3. （如果有密码）输入密码
4. 点击"加入游戏桌"
5. ✅ 立即开始游戏！

### 场景 2：快速开始一局

1. 在游戏大厅找到想玩的游戏
2. 点击"快速开始"
3. 系统自动查找等待中的桌子
4. 如果找到 → 直接加入
5. 如果没找到 → 创建新桌并等待其他玩家
6. ✅ 匹配成功后开始游戏！

### 场景 3：邀请在线好友

**在游戏桌内：**
1. 点击"邀请好友"
2. 看到在线好友列表
3. 点击某个好友的"邀请"按钮
4. 好友收到浮动通知
5. 好友点击"加入"
6. ✅ 好友立即进入游戏桌！

### 场景 4：浏览公开游戏

1. 在游戏大厅向下滚动
2. 查看"公开游戏桌"列表
3. 看到桌号、游戏类型、玩家数量
4. 点击"加入游戏桌"或"观战"
5. ✅ 进入游戏！

## 📋 功能详解

### 桌号系统

**桌号格式**：4-6 位数字（如 #1234）

**特点**：
- 每个桌子都有唯一桌号
- 简单易记，方便口头传达
- 支持直接输入加入

**使用方法**：
```
创建桌子 → 系统自动生成桌号 → 分享给好友
好友输入桌号 → 验证（如有密码）→ 成功加入
```

### 密码保护

**何时使用**：
- 只想和特定好友玩
- 不想陌生人加入
- 创建私密房间

**设置方法**：
1. 创建桌子时
2. 勾选"设置密码保护"
3. 输入密码（4-16位）
4. 桌子显示 🔒 图标

**加入方法**：
- 输入桌号后，会提示输入密码
- 密码正确才能加入

### 快速匹配

**工作原理**：
1. 查找相同游戏类型的等待桌
2. 如果找到有空位的 → 直接加入
3. 如果没找到 → 创建新桌并广播匹配请求
4. 其他匹配者看到请求 → 自动加入
5. 60秒超时 → 提示邀请好友

**适用场景**：
- 想快速开始游戏
- 不在意和谁玩
- 体验匹配系统

### 邀请系统

**邀请流程**：
```
桌主点击"邀请好友"
  ↓
选择在线好友
  ↓
发送邀请
  ↓
好友收到浮动通知（右上角）
  ↓
好友点击"加入"或"拒绝"
  ↓
成功加入或取消
```

**邀请通知**：
- 显示在屏幕右上角
- 包含游戏名称和桌号
- 5分钟后自动过期

## ❓ 常见问题

### Q1：桌号忘记了怎么办？
**A**：桌号会显示在游戏桌的标题栏（如 ⚫ 五子棋 #1234）

### Q2：密码忘记了怎么办？
**A**：只能让桌主重新创建桌子。密码无法找回（出于安全考虑）

### Q3：快速匹配一直找不到人？
**A**：
- 可能该游戏玩家较少
- 建议切换到邀请好友
- 或者在大厅浏览公开桌子

### Q4：邀请发出去但对方没反应？
**A**：
- 对方可能不在线
- 邀请可能已过期（5分钟）
- 重新发送邀请

### Q5：桌号会重复吗？
**A**：
- 不会，系统确保唯一性
- 如果碰撞会自动重试
- 桌子销毁后5分钟才回收桌号

### Q6：私密桌和公开桌有什么区别？
**A**：
- **公开桌**：所有人可见，可从大厅列表加入
- **私密桌**：不在列表显示，只能通过桌号或邀请加入

### Q7：为什么我的邀请发不出去？
**A**：
- 对方可能已断开连接
- 检查网络状态
- 尝试刷新页面

### Q8：加密桌的密码安全吗？
**A**：
- 密码不会明文传输
- 使用哈希验证
- 适合朋友间使用
- 不建议用于高安全场景

## 🔧 技术说明

### 桌号生成规则
- 起始长度：4位数字
- 最大长度：6位数字
- 自动碰撞检测
- 延迟回收机制

### 匹配算法
1. 查找等待桌（人多的优先）
2. 检查空位
3. 验证密码（如需要）
4. 加入或创建

### 邀请机制
- P2P 直接传输
- 5分钟超时
- 自动清理过期邀请
- 支持批量邀请（未来）
