### 2. ✅ 添加快速匹配功能

**功能描述**：
自动匹配想玩同一游戏的玩家，无需手动创建和加入桌子。

**工作流程**：

1. **用户 A 点击"快速匹配"**
   - 显示匹配中遮罩
   - 广播匹配请求
   - 加入匹配队列

2. **用户 B 也点击"快速匹配"（同一游戏）**
   - 收到 A 的匹配请求
   - 立即匹配成功

3. **匹配成功后**
   - A 自动创建游戏桌
   - B 自动加入游戏桌
   - 双方进入游戏界面

**UI 界面**：

│                                 │
│      [取消匹配]                 │

## 技术实现

### 匹配消息协议

新增三种消息类型：

```typescript
| { kind: 'match-request'; gameType: string }  // 请求匹配
| { kind: 'match-cancel'; gameType: string }   // 取消匹配
| { kind: 'match-found'; tableId: string; gameType: string }  // 匹配成功
```

### Store 状态

```typescript
// 匹配队列：gameType -> 等待匹配的玩家 ID 列表
const matchingQueues = reactive(new Map<GameType, string[]>())

// 当前正在匹配的游戏类型
const myMatchingGame = ref<GameType | null>(null)
```

### 关键函数

```typescript
// 开始匹配
startMatching(gameType: GameType): void

// 取消匹配
cancelMatching(gameType: GameType): void

// 匹配成功（内部使用）
matchWith(partnerId: string, gameType: GameType): void
```

### 匹配算法

**简单队列匹配**：
1. 用户 A 开始匹配 → 广播 + 加入队列
2. 用户 B 开始匹配 → 收到 A 的请求 → 立即匹配
3. A 创建游戏桌 → 通知 B → B 自动加入

**特点**：
- P2P 架构，无需中心服务器
- 先到先得
- 实时匹配（无延迟）
- 支持多种游戏同时匹配

## 使用场景

### 场景 1：快速开始游戏

1. 用户打开游戏大厅
2. 看到"五子棋"，点击"快速匹配"
3. 等待 3-5 秒
4. 匹配到另一个玩家
5. 自动进入游戏桌，开始游戏

**优势**：无需手动创建桌子、等待别人加入

### 场景 2：创建私密桌子

1. 用户打开游戏大厅
2. 点击"象棋"的"创建桌子"
3. 对话框中选择"私密桌子"
4. 创建后邀请好友
5. 好友加入后开始游戏

**优势**：只和好友玩，不被打扰

### 场景 3：加入现有桌子

1. 用户打开游戏大厅
2. 看到"公开游戏桌"区域有桌子在等待
3. 点击"加入游戏桌"
4. 进入桌子，等待开始

**优势**：可以选择特定的桌子加入
